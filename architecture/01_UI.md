# 🏛️ Component 01 — UI / UX Design Language Specifications

## 🎨 Visual Identity & Aesthetic Mood
- **Atmospheric Canvas**: Implements a high-contrast dark visual theme ("Amber-Slate Dark") to minimize optical strain in operational settings.
- **Surface Elevation Hierarchy**: Uses a background level of pure charcoal dark slate (`#09090b`), container cards styled with elevated slate surfaces (`#18181b`), and active highlighted states to separate elements visually.
- **Accent Rhythm**: Leverages electric amber (`#f59e0b`) for active warnings/geofences and vibrant cyan/emerald for secure, compliant elements.

## 📋 Status Indicator & Design Elements
- **Interactive States**: Flat styled inputs with elegant margins, paired with micro-movements provided by `motion` from `motion/react`.
- **Arabic Translation Accessibility**: High fidelity RTL layout support for critical business components, using direct native translations.
- **Real-time Clock Banner**: An ambient status display combining current regional timezone indicators and live tracking statuses.
