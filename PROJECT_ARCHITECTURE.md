# 🏛️ NexaLedger - Enterprise Project Architecture & Status board 

Welcome to the ultimate governance index of NexaLedger. This architecture matrix splits our entire mission-critical application into **12 Key High-Fidelity Modules**. Every update, modification, or expansion must synchronize across these modules to preserve architectural integration and absolute alignment with the Saudi Personal Data Protection Law (SDPL), WebAuthn specifications, and Enterprise Cloud scale.

---

## 🗺️ Master Index of Architecture Modules

1. **[UI / UX Design Language](./architecture/01_UI.md)** — Core aesthetic mood, Tailwind CSS variables, user interfaces, Dark theme, and responsive negative space rhythm.
2. **[Frontend Framework](./architecture/02_FRONTEND.md)** — React 19, custom hooks, atomic components, and Leaflet/Google Maps GIS layer state integrations.
3. **[Backend / APIs](./architecture/03_BACKEND_APIS.md)** — Express Router, security middleware, biometric payload validations, and logging endpoints.
4. **[Database Schemas](./architecture/04_DATABASE.md)** — Firestore document blueprints, collection layouts, offline persistence, and indexed queries.
5. **[Server Engine](./architecture/05_SERVER.md)** — Isomorphic Node.js development server running on Port `3000` with automated bundle compilers.
6. **[Networking & Routing](./architecture/06_NETWORKING.md)** — Ingress reverse proxy configuration, SPA route fallback, and WebSocket telemetry bounds.
7. **[Security & Integrity Guard](./architecture/07_SECURITY_INTEGRITY.md)** — WebAuthn FIDO2 hardware biometric registry, anti-spoofing engine, and location hacking defenses.
8. **[Notification & Push Matrix](./architecture/08_NOTIFICATIONS_PUSH.md)** — Cloud FCM (Firebase Cloud Messaging) Service Worker integration.
9. **[Geofencing & Spatial Systems](./architecture/09_GEOFENCING_LOGISTICS.md)** — High-precision geofencing, distance computations, and dynamic worksite boundaries.
10. **[Documentation & Reports](./architecture/10_DOCUMENTATION_REPORTS.md)** — Automated reporting with pdf/excel rendering engines.
11. **[Permissions & Privacy Shield](./architecture/11_PERMISSIONS_PRIVACY.md)** — Strict SDPL compliance layer, employee tracking classification, and personal GPS data masking rules.
12. **[Deployment & Integration](./architecture/12_DEPLOYMENT_INTEGRATION.md)** — Cloud Run runtime constraints, dev/prod compiling flows, and environment declarations.
